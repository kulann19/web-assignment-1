# Assignment 1 — HTML & CSS Basics

Student project for the front-end development course at Astana IT University.

**Author:** Kulan Alnur
**Group:** SE-2524

## Description

A small multi-page website built with plain HTML and CSS. Every task of the
assignment is placed on its own page, and all pages are connected through a
navigation bar at the top. No frameworks or libraries are used.

## Pages

| Page   | Folder       | Description                                                   |
| ------ | ------------ | ------------------------------------------------------------- |
| Home   | `/`          | Start page with links to all tasks                            |
| Task 1 | `/task1`     | Personal page with a profile card, lists, image and links     |
| Task 2 | `/task2`     | Two-column layout built only with div elements and CSS floats |
| Task 3 | `/exercise1` | Tribute page about Nikola Tesla                               |
| Task 4 | `/task4`     | Styled table with student grades and a feedback form          |

## What was used

- Semantic HTML structure: headings, paragraphs, ordered and unordered lists,
  images with alt attributes, tables and form elements
- CSS selectors: element, class and ID
- Colors, fonts, margins, padding and borders
- Float based layout without flexbox and grid (Task 2)
- Table styling with `nth-child` for alternating rows, `rowspan` and `colspan`
- Google Fonts and a gradient background (Task 3)
- Hover effects on navigation and links
- Responsive behaviour through media queries

## How to run locally

1. Download or clone this repository.
2. Open the project folder in a code editor.
3. Open `index.html` in a browser, or use the Live Server extension in
   Visual Studio Code.
