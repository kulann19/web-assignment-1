About This Layout

This page is built only with div elements and CSS floats. The menu on the left is floated to the left side, and this content block is floated to the right. No flexbox and no grid are used here.

How It Works

The header sits at the top of the page and the navigation bar is placed right under it. Both columns are wrapped in one container, and a clearing element below them makes the footer stay at the bottom instead of sliding up next to the floated blocks.
